# Experiment files

- `robot_navigation_results.xlsx` contains the original odometry and tracking
  experiment table with formulas, means, sample standard deviations,
  covariance calculations and distance–time correlation coefficients.
- `odometry_results.csv` contains the ten odometry-phase records.
- `tracking_results.csv` contains the ten tracking-phase records.
- `summary_statistics.csv` contains the derived summary values for both phases.

The CSV files were transcribed from the workbook to make the measurements easy
to inspect and reuse without changing the experimental values.
